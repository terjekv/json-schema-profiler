# schema_analysis notices

These are the unmodified MIT and Apache-2.0 license texts distributed with
`schema_analysis` 0.7.0 (crates.io archive SHA-256
`04dd8374f226542344bb23631f626fc40b99526ef431148270d89b74611d6a49`).
They accompany the source patch in `patches/schema-analysis-object-presence.patch`
and are included in the profiler's Cargo archive. Cargo excludes the separate
vendored package, so its license copies alone would not be distributed there.

The [vendored package](https://github.com/terjekv/json-schema-profiler/tree/main/vendor/schema_analysis)
also retains the original notices alongside its runtime source. The license
inventory in `docs/dependency-licenses.md` covers the remaining dependency graph;
their full sources and notices are supplied by their own dependency packages.
